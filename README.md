# tools

Small personal tools.

## Chrome extensions

See [chrome-extensions/](chrome-extensions/README.md) for how to build and load them.

| Tool | What it does |
| --- | --- |
| [page-review](chrome-extensions/page-review) | Review any web page like a pull request. Comment on text, then copy the comments as a prompt for an AI agent. Works well with [mo](https://github.com/k1LoW/mo). |
